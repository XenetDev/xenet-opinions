# Sidebar with chat history implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A persistent left sidebar (logo, New chat, ⌘K search, chat history by day, usage card, theme, guide, account) replaces the header's chat dropdown, the home page's recent list and the usage line above the composer.

**Architecture:** shadcn `Sidebar` primitives (pulled in through ReUI `app-shell-21`) wrap the chat layout in `SidebarProvider`; `AppSidebar` under `modules/chat/shell/` reads the existing `ChatListProvider` and a new `UsageProvider` seeded by the server layout. The header keeps title, Working badge and chat options; a mobile menu button opens the sidebar sheet. The palette is the repo's `CommandDialog`.

**Tech Stack:** Next 16 App Router, React 19, shadcn sidebar/command/sheet, ReUI badge, next-themes, Vitest + Testing Library + vitest-axe, Biome.

**Spec:** `docs/superpowers/specs/2026-10-29-sidebar-design.md`

## Global Constraints

- Copy exact: "Xenet Opinions", "New chat", "Search chats", groups "Today", "Yesterday", "Previous 7 days", "Previous 30 days", then month labels like "October 2026"; empty states "No chats yet" and "Chats on this device only. Sign in to keep them."; usage card "Runs today", `{used} of {max}`, `Resets {resetLabel}` / `No runs left until {resetLabel}`, "Sign in for {n} runs a day", button "Sign in"; footer links "Theme", "How it works"; `aria-label`s "Open sidebar", "Working", "Chat options", "Account menu".
- Shortcuts: `⌘K`/`Ctrl+K` palette (preventDefault), `⌘⇧O`/`Ctrl+Shift+O` new chat, shadcn `⌘B` sidebar toggle; all work with the composer focused.
- Collapsed by default below 1024 px with no `sidebar_state` cookie; mobile (< 768 px) is the sheet. `prefers-reduced-motion` disables the collapse animation and the pulsing dot.
- Do not overwrite existing `components/ui` files when installing; do not keep `resizable`, `toggle-group` or `react-resizable-panels`.
- Single source for chats: `ChatListProvider`. Strict TS, Biome, comments only for invariants, axe clean, gates (`pnpm lint && pnpm typecheck && TEST_DATABASE_URL=postgresql://xo:xo@localhost:55432/xo_test pnpm test && pnpm --filter web build && pnpm check:licenses`) green per task.

## Review Focus

1. A chat whose run finishes while the sidebar is open loses its dot and keeps its place; a new run re-sorts it to the top of "Today". (Task 3 tests)
2. A guest with no sign-in provider sees the usage card without the Sign in button and no account row, and nothing crashes while the session is still pending. (Task 2, Task 3 tests)
3. Deleting the open chat from the header menu removes its sidebar row and goes home; renaming updates the row and the header title. (Task 4 test)
4. Opening the palette with the composer focused, typing, Escape: focus returns to where it was and the composer text is intact. (Task 5 test)
5. First paint on a 1280 px desktop with no cookie is expanded; with `sidebar_state=false` it is the rail, with no flash. (Task 4 layout test)
